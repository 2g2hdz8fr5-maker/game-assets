# 塔防游戏素材合集

## 目录结构

```
game-assets/
├── towers/
│   ├── stone-towers/          # 28个石塔PNG - 高质量奇幻风格
│   ├── basic-tower/           # 3D塔模型(FBX)
│   └── basic-towers-psd/      # 5个高清塔PNG + PSD源文件(Cannon/MG/Missile)
├── enemies/                   # 敌人精灵图(待补充)
├── backgrounds/
│   ├── bg-mountain.png        # 山脉背景(1.4MB)
│   └── bg-td-painting.png     # TD手绘背景(688KB)
├── tiles/
│   └── kenney-td-300/         # Kenney塔防300素材包 - 地图瓦片/塔/敌人/HUD
└── ui/                        # UI素材(待补充)
```

- **守卫山河** → stone-towers 替换现有塔精灵 + kenney-td-300 瓦片优化地图 + bg-mountain 做背景
